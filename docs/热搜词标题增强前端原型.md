# 热搜词标题增强前端原型

## 页面位置

放在现有商品详情页的 `AI 文案工作台` 内，不新增一级页面。热搜词能力作为标题生成增强项出现，默认关闭，不影响当前“启动生成”按钮的原始行为。

## 页面结构

1. 顶部工具栏保留现有按钮：启动生成、按意图重写、规则校验、保存版本。
2. 在生成按钮左侧增加一个紧凑开关区：
   - 开关名：热搜词增强
   - 状态文案：全局默认关闭 / 全局默认开启 / 本次手动开启 / 本次手动关闭
   - 辅助信息：最近热搜词批次、匹配类目、可用词数量
3. 在生成过程面板中增加一步：热搜词筛选。
4. 在模型输出草稿下方增加一个“热搜词覆盖”区域：
   - 可用热搜词：展示最多 10 个词
   - 已命中：绿色标签
   - 未命中：红色标签
   - 已过滤：灰色标签，悬停显示过滤原因

## 核心交互

1. 初次进入页面时，前端读取全局配置。
2. 如果全局默认关闭，开关处于关闭状态；用户可为本次生成手动开启。
3. 如果全局默认开启，开关处于开启状态；用户可为本次生成手动关闭。
4. 点击“启动生成”时，前端传 `use_hot_search`：
   - 用户未手动改动：不传，让后端使用全局默认。
   - 用户手动开启：传 `true`。
   - 用户手动关闭：传 `false`。
5. 生成完成后，前端展示后端返回的 `selected_hot_terms`、`matched_hot_terms`、`missing_hot_terms`、`excluded_hot_terms`。

## 状态变化

1. 未上传热搜词数据：开关可点，但生成后提示“当前商品类目没有可用热搜词”。
2. 已上传但类目不匹配：展示匹配类目为空，生成失败不覆盖原标题。
3. 已匹配且生成成功：标题进入草稿区，热搜词覆盖区域同步更新。
4. 生成标题缺少热搜词：展示校验未通过，标题不落库，保留原草稿。
5. 用户关闭热搜词增强：生成过程和校验结果不展示热搜词要求。

## 边界情况

1. 热搜词全部被规避词过滤：展示过滤词和原因，不调用模型。
2. 男款出现女童词、女款出现男童词：进入已过滤区域，原因显示为性别冲突。
3. 标题只包含热搜词散字但不连续：按未命中处理。
4. 模型超时或返回非 JSON：沿用现有错误展示，不覆盖原文案。
5. 全局配置保存失败：开关恢复到上一次状态，并展示错误提示。
