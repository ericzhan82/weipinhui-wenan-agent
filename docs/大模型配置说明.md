# 大模型配置说明

系统通过轻量 LLM Adapter 调用模型，一期不依赖 LangChain。

## mock

```env
LLM_PROVIDER=mock
LLM_MODEL=mock
```

特点：

- 不调用外部服务。
- 不需要 API Key。
- 返回稳定 JSON。
- 适合本地演示和 Docker Compose 验收。

## openai-compatible

```env
LLM_PROVIDER=openai_compatible
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://your-compatible-endpoint/v1
LLM_MODEL=your-model-name
LLM_TIMEOUT_SECONDS=60
LLM_TEMPERATURE=0.4
```

要求：

- 不硬编码密钥。
- 不在日志或前端展示密钥。
- 模型输出必须是 JSON。
- JSON 解析失败时后端返回明确错误。
