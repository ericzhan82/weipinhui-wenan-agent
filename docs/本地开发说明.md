# 本地开发说明

## 后端

```bash
cd backend
python -m venv ../.venv
../.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
../.venv/Scripts/python.exe -m uvicorn main:app --reload --port 8000
```

## 前端

```bash
cd frontend
npm install
npm run dev
```

## 测试

```bash
.venv/Scripts/python.exe -m pytest backend/tests -q
cd frontend
npm run build
```

## Docker Compose 验收

安装并启动 Docker Desktop 后，在项目根目录运行：

```powershell
.\scripts\verify_docker.ps1
```

Windows 首次安装 Docker Desktop，或刚启用 WSL / Virtual Machine Platform / Hyper-V 后，通常需要重启 Windows。脚本会先执行 Docker Engine 预检；如果 Engine 未就绪，会停止在 compose 构建之前并提示处理方式。

Linux/macOS 可运行：

```bash
bash scripts/verify_docker.sh
```
