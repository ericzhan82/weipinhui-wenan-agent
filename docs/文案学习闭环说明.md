# 文案学习闭环说明

系统不是自动替代人工审核的 Agent，而是具备人工反馈闭环的文案优化系统。

## 流程

1. 模型生成文案并保存 `model_generated` 版本。
2. 人工编辑文案并保存 `manual_edit` 版本。
3. 学习中心读取版本差异。
4. 固定脚本统计修改方向、高频保留词、高频删除词。
5. 写入 `learning_reports`。
6. 生成 `rule_suggestions`，默认 `pending`。
7. 人工接受后才写入 `rules`。
8. 人工拒绝后建议状态变为 `rejected`。

## 边界

- 系统不会自动让规则建议生效。
- 系统不会编造商品资料中不存在的卖点。
- 系统不能保证一定提升转化率。
- 平台合规风险仍需人工复核。
