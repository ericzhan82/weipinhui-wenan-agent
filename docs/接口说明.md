# 接口说明

## 基础

- `GET /api/health`
- `GET /api/llm/status`

## 商品与 SKC

- `GET /api/products`
- `POST /api/products`
- `GET /api/products/{product_id}`
- `PUT /api/products/{product_id}`
- `DELETE /api/products/{product_id}`
- `POST /api/products/{product_id}/skus`
- `PUT /api/skus/{sku_id}`
- `DELETE /api/skus/{sku_id}`

## 文案

- `POST /api/products/{product_id}/generate-copy`
- `POST /api/products/{product_id}/rewrite-copy`
- `PUT /api/products/{product_id}/copy`
- `POST /api/products/{product_id}/validate-copy`
- `GET /api/products/{product_id}/copy-versions`
- `POST /api/products/{product_id}/copy-versions/{version_id}/restore`

## 历史、规则、学习

- `GET /api/history-cases`
- `POST /api/products/{product_id}/save-history-case`
- `GET /api/rules`
- `POST /api/rules`
- `PUT /api/rules/{rule_id}`
- `DELETE /api/rules/{rule_id}`
- `GET /api/learning/summary`
- `POST /api/learning/analyze`
- `GET /api/learning/reports`
- `GET /api/learning/suggestions`
- `POST /api/learning/suggestions/{suggestion_id}/accept`
- `POST /api/learning/suggestions/{suggestion_id}/reject`

## Excel

- `POST /api/excel/import`
- `GET /api/excel/export`
- `GET /api/excel/export/{export_id}/download`
