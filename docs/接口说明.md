## 文案

- `POST /api/products/{product_id}/generate-copy`
  - 可选请求体：`{"use_hot_search": true | false, "agent_mode": "legacy" | "business_agent" | "openai_agents" | "claude_agent"}`
  - 未传 `use_hot_search` 时使用热搜词全局默认配置。
  - 未传 `agent_mode` 时使用 Agent 全局默认配置；默认配置关闭时走 `legacy`。
  - 响应可能包含：`hot_search_enabled`、`selected_hot_terms`、`matched_hot_terms`、`missing_hot_terms`、`excluded_hot_terms`、`hot_search_source_batch`、`agent_run_id`、`agent_steps`。
- `POST /api/products/{product_id}/generate-copy-job`
  - 可选请求体同 `generate-copy`，用于创建后台任务号。
- `GET /api/products/{product_id}/agent-runs/latest`
  - 返回最近一次 Agent 运行记录和步骤；没有运行记录时返回 `null`。
- `POST /api/products/{product_id}/rewrite-copy`
- `PUT /api/products/{product_id}/copy`
- `POST /api/products/{product_id}/validate-copy`
- `GET /api/products/{product_id}/copy-versions`
- `POST /api/products/{product_id}/copy-versions/{version_id}/restore`

## 热搜词标题增强

- `GET /api/hot-search/config`
  - 返回：`enabled_by_default`、`updated_by`。
- `PUT /api/hot-search/config`
  - 请求体：`{"enabled_by_default": false, "updated_by": "operator"}`
  - 用于设置热搜词标题增强的全局默认开关，默认值为 `false`。
- `POST /api/hot-search/import`
  - 表单字段：`file`，仅支持 `.xlsx`。
  - 数据源至少需要包含“搜索词主分类”和“关键词”，可额外包含排名、UV、机会、成交、销量等指标。

## Agent 运行时

- `GET /api/agent/config`
  - 返回：`enabled_by_default`、`default_agent_mode`、`allow_sdk_modes`、`available_modes`。
- `PUT /api/agent/config`
  - 请求体：`{"enabled_by_default": false, "default_agent_mode": "legacy", "allow_sdk_modes": false, "updated_by": "operator"}`
  - `business_agent` 会记录“上下文检查、规则读取、热搜词策略、文案生成、业务校验、学习建议”步骤。
  - `openai_agents` 和 `claude_agent` 是预留 SDK 运行时，默认禁用；未安装对应 SDK 或未开启 `allow_sdk_modes` 时会返回清晰错误。
